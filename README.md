# 每日事件工作台 · 本地 HTML 分享版

一个中文单文件日程与待办管理工具。下载 `每日事件.html`，用现代浏览器打开即可使用，无需安装依赖、注册账号或启动服务器。

> **本版本不支持多设备同步。** 所有事件、排序和主题设置保存在当前浏览器的 `localStorage` 中。电脑、手机、不同浏览器、不同浏览器用户配置之间不会自动同步。即使登录了同一个 GitHub 账号，也不会同步事件数据。

## 本次修复

- **多窗口保存：** 每个窗口只保存实际修改，并合并其他窗口的新内容，避免用整份旧数据覆盖新记录。不同事件或不同字段可合并；检测到相同内容冲突时，保留本窗口的未保存修改，提示选择保留哪一版。极短时间内同时改动相同内容时，会提示核对合并结果。
- **保存失败提示：** 无法访问本地存储或存储空间不足时，页面显示提示和重试入口，不会把失败当作保存成功；未保存内容仍保留在当前窗口，离开时会触发浏览器的未保存提醒（是否显示取决于浏览器）。
- **大量事件性能：** 建立事件和日期统计索引，整理排序时使用集合去重，避免渲染每一天时重复扫描全部事件。

更新时请让同一副本的所有窗口使用新版本。旧版不会读取新版用于多窗口合并的本地修改片段。

## 功能说明

| 功能 | 具体说明 |
| --- | --- |
| 新增事件 | 填写事件名称、完成状态、安排日期、颜色、提醒标记和事件说明。名称必填，其他信息可按需要设置。 |
| 编辑与删除 | 点击事件卡片上的编辑按钮修改内容；删除事件前会弹出确认。 |
| 待办事件池 | 未指定日期的事件集中显示，可在池内拖动调整顺序。 |
| 日期安排 | 从事件池拖入某一天的空位，或通过表单直接指定日期；也可以把事件拖回事件池取消日期安排。 |
| 拖动排序 | 在同一天内调整事件位置，也能拖动到其他日期。未完成与已完成事件分组显示，未完成事件优先。 |
| 完成状态 | 勾选事件卡片上的复选框切换完成状态，完成事件时显示彩纸动画。 |
| 每日统计 | 每天显示事件总数和已完成数量，并标出今天。 |
| 连续日期列表 | 初始显示从今天起的一段日期；滚动时追加日期，方便连续安排。 |
| 大日历 | 支持切换月份，查看每天的总计、已完成及未完成数量，点击日期跳转到该天。 |
| 回到今天 | 一键定位今天的安排。 |
| 事件颜色 | 为不同事件设置卡片颜色。 |
| 提醒标记 | 支持无标记、❗、❗❗三种视觉标记，用于区分紧急程度；不会发送定时通知、声音、系统推送或邮件。 |
| 自定义主题 | 设置工作台名称、说明文字、主颜色、辅助颜色和页面背景颜色。 |
| 自动本地保存 | 事件、排序和主题设置自动保存到当前浏览器，无需另点“保存全部”；失败时明确提示，可重试。 |
| 同一浏览器多窗口 | 合并共享同一份本地存储的窗口修改，并提示冲突；这不代表不同设备之间可以同步。 |
| 响应式布局 | 包含桌面、平板和窄屏布局。手机可用表单设置日期；拖放操作依赖浏览器支持，桌面鼠标体验更完整。 |
| 快捷关闭弹窗 | 点击关闭按钮、弹窗外区域或按 Esc 可关闭日历与设置弹窗。 |

## 如何使用

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**，下载并解压。
2. 用现代浏览器打开解压后的 **每日事件.html**。
3. 点击“+ 新增事件”，填写内容，点击“保存事件”。
4. 未指定日期的事件会进入“待办事件池”；拖入日期，或在表单中选择日期即可安排。
5. 使用勾选框记录完成情况，用“打开日历”和“回到今天”定位日期。
6. 点击标题旁的齿轮按钮修改工作台名称、说明和主题。

表单中的“清空”只清空当前编辑表单，不是删除全部事件。

## 数据存储与同步限制

- **没有账号系统、服务器、云数据库或自动同步功能。**
- GitHub 在这里仅用于分享程序源码，不负责保存、备份或同步你填写的事件。
- 为了避免多窗口互相覆盖，新版会在相同前缀下保留本地修改片段；这些内容同样只保存在本机，不上传。修改片段会占用本地存储空间，删除一个事件不等于清除所有历史片段。
- 事件保存在当前浏览器环境的本地存储中；刷新或重新打开时，只有浏览器仍保留同一份存储才能恢复。
- 更换设备、浏览器或浏览器用户配置，不会自动获得原来的记录。
- **复制或发送 HTML 文件只会分享程序，不会把已填写事件一起带走。**
- 本版本没有内置数据导入、导出、账号登录、云备份或多设备同步按钮。
- 清除浏览器网站数据、使用隐私模式、存储被浏览器回收或更换文件位置，都可能使原来的数据丢失或无法访问。
- 直接以 `file://` 打开的文件，其本地存储行为受浏览器影响；不要把移动、改名或复制文件当作可靠的数据备份方式。
- 即使另行托管为静态网页，也不会因此获得跨设备同步能力；数据仍在访问者自己的浏览器里。

## 分享版隔离与隐私

本仓库仅包含独立 HTML 程序、此说明和提交文件白名单，不包含任何人的事件记录、浏览器数据、账号凭据、个人截图或云端配置。

为了与个人自用副本区分，本分享版使用**独立的本地存储键名**：

```text
daily_event_workbench_github_share_v1
```

在本地原版功能基础上，分享版增加了上面的三项修复。分享版不会主动读取或迁移个人原版存储键下的记录；在同一个浏览器来源下，也不会使用个人原版的存储键。程序应从独立下载目录打开，不覆盖个人日常使用文件。

- 默认事件列表为空，收件池顺序和每日排序均为空。
- 程序不包含外部脚本、远程图片、统计代码、联网请求或数据上传功能；打开本地文件后可离线使用。
- 每个使用者填写的内容留在自己的浏览器中，程序不会把事件提交到 GitHub 或发送给仓库作者。
- 本地保存不等于加密：能访问同一浏览器用户配置的人可能读取数据；公共或共用电脑不适合保存敏感记录。
- 若通过第三方静态托管访问，托管平台可能记录通常的网页访问日志；这与本程序没有事件上传功能是两回事。
- 本地存储键用于区分版本，不是安全隔离容器；同一网站来源下的其他脚本仍可能访问该来源的存储。请在可信环境中使用。

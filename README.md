# 每日事件工作台 · 循日录

**先把事情全部收集进待办池，再把事件拖到日期里安排每天；计划变化时直接拖来拖去。**

待办池不是普通的完成清单，它是尚未排期的事件集合。你可以先只写下事件名称、不选日期，集中整理完所有事情，再从待办池拖到某一天；也可以跨日期改期、拖回待办池，或在同一天和待办池里调整先后顺序。移动的是同一条事件，不会复制出多份。

本仓库包含两个版本，界面和排期流程一致，数据保存方式不同：

| 版本 | 打开方式 | 数据保存 | 多设备同步 |
| --- | --- | --- | --- |
| [每日事件.html](每日事件.html) | 下载后用现代浏览器打开 | 当前浏览器本地存储；可导入/导出 JSON | **没有账号，不会自动同步**；手工导出再导入才能转移 |
| [cloud/](cloud/) 云端源码 | 先部署服务器、数据库和可信登录服务 | 按登录用户保存在数据库，同时缓存未同步修改 | 配置并部署后，同一账号可在电脑和手机同步 |

**GitHub 代码备份、GitHub Pages 和下载 HTML 本身都不会自动获得云同步。** `cloud/` 保留了 Sites 托管适配，不能把它当成任意静态空间上即开即用的登录服务。公开源码不包含已部署私有网站的身份配置、数据库或用户事件。

## 快速使用

1. 下载整个仓库或 ZIP，解压后打开根目录 `每日事件.html`。
2. 点击“新增事件”，不填日期，保存到待办池。重复添加，把事情先列全。
3. 电脑拖动事件卡片到日期区域；手机拖动卡片右侧的六点手柄到日期。
4. 在日期之间拖动改期，拖回待办池取消排期，在列表内拖动调整顺序。
5. 点击勾选框完成事件；右侧“…”打开“编辑事件 / 删除事件”。
6. 定期从顶部“备份”菜单导出 JSON，单独保存在私人位置。

手机上日期区和待办池保持同屏：上方浏览每日安排，下方浏览待办。**滑动卡片正文是浏览，拖动六点手柄才是排期**。回到今天后，向下拉动日期列表可以回看前几天，继续靠近列表顶部可加载更早的一周。

## 已包含的更新

- 手机布局、视口宽度约束、安全区适配、表单弹窗。
- 同屏拖动排期、跨日期移动、移回待办和列表排序。
- 手柄触摸拖动、禁用卡片文字长按选择；拖动帧合并、位置缓存、按时间计算的边缘滚动。
- 默认预载今天之前七天，打开时定位今天；向前加载历史时保持当前阅读位置。
- 待办与日期卡片使用相同的顶层操作弹窗，只有编辑和删除，避免被滚动区域裁切。
- 本地保存失败提示、多窗口修改合并与冲突选择；云端版另有登录同步、离线草稿和并发版本检查。
- JSON 导入、导出；事件状态、颜色、提醒标记、说明、日历跳转和外观设置。

## 目录与验证

- `每日事件.html`：独立版完整页面，无需安装依赖。
- `cloud/`：云端前后端源码、数据库结构/迁移、构建脚本及依赖锁文件。
- `docs/`：功能、使用、部署、恢复、隐私和版本说明。
- `tests/`：可复现的回归检查，仅使用虚构测试数据。
- `SHA256SUMS.txt`：本次源码备份的文件校验值。

安装 Node.js 后，在仓库根目录依次运行：

```sh
node tests/local.cjs
node tests/local-mobile.cjs
node tests/cloud.cjs
node tests/markup.cjs
```

云端构建方法见部署指南。测试通过不代表所有手机硬件都已实测；触屏交互仍应在目标设备上验证。源码包不含依赖安装目录、构建产物和用户数据。

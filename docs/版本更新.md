# 版本更新 · 2026-10-29 归档

本次把后续更新整理为一个公开源码快照，同时提供独立 HTML 与经过身份配置清理的云端源码。

1. **保存与并发**：保留保存失败提示、重试和多窗口冲突处理；云端按 revision 写入并合并离线草稿。事件索引用于避免重复扫描列表。
2. **手机布局**：日期和待办同屏，上下区域分别浏览；编辑表单使用弹窗，适配安全区与窄屏宽度。
3. **核心拖动恢复**：六点手柄用于待办到日期、跨日期、回待办、同列表调序；正文保留自然滚动。
4. **iPhone 触摸改进**：页面内拖动预览、减少文字长按选择干扰，动画帧合并、缓存目标位置、按时间计算边缘滚动、增量追加日期。
5. **历史回顾**：预载今天之前七天并定位今天，向下拉动可回看；到顶部继续加载更早一周，保留阅读位置。
6. **操作菜单**：待办和日期卡片均打开顶层操作弹窗；仅保留编辑和删除，移除菜单里的上下移动；先关菜单再开编辑器。
7. **独立版归档**：同步上述布局及交互，继续使用分享版独立本地存储；补充 JSON 导入导出，明确没有账号与自动跨设备同步。
8. **文档与隐私**：补齐功能、工作流、部署、迁移恢复、快捷方式与备份边界；不携带用户数据及原私有站点身份。

验证方式：独立版本地存储检查、独立版手机交互检查、云端同步与手机交互检查、静态结构检查，以及清理身份配置后的云端构建。手机自动检查采用模拟触摸和布局对象，不能代表真机实测流畅度。

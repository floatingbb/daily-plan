# 隐私与备份

## 公开包的范围

公开仓库和本次 ZIP 只含程序源码、通用配置、文档、虚构测试用例和校验清单。初始事件数组为空，没有个人课程、任务、完成记录、导出的 JSON、账号邮箱、私人网站网址、原站点项目标识、数据库文件、部署凭据、浏览器缓存或截图。GitHub 用户名及公开提交作者信息仍属于仓库元数据。

两个版本均不内置用户使用记录。云端浏览器缓存中的当前身份由服务器在运行时注入；源码保留占位符，不注入实际账号。数据库迁移只有表结构，没有 INSERT 种子记录。

## 两种备份分别保存

| 备份 | 保存内容 | 恢复能力 |
| --- | --- | --- |
| 本次源码 ZIP / GitHub | 页面、后端、数据库结构、依赖锁、说明 | 恢复程序、继续开发和重新部署 |
| 页面导出的私人 JSON | 当前事件、状态、顺序、设置 | 在页面导入，恢复你的使用数据 |

**源码 ZIP 不含你的事件记录。** 要完整保存个人成果，请另从自己正在使用的网页导出 JSON，并将它放在私人备份位置。不要把 JSON、截图、数据库、浏览器资料目录或云端工作区链接提交到公开 GitHub。

仅复制 HTML 文件、建立快捷方式或下载 GitHub 仓库，都不会自动带走浏览器存储。清理网站数据、无痕模式结束、更换浏览器或文件位置可能使本地记录不可见或丢失。

## 发布与后续维护

根目录 `.gitignore` 排除了依赖、构建产物、运行目录、常见密钥文件及备份数据目录。忽略规则只是防止误加入，不会自动清除已经跟踪的文件。以后每次提交前仍应检查新增文件和差异，尤其不要将导出的 JSON 放到源码目录中。

原个人 HTML 与公开分享版使用不同存储命名空间。本次整理不修改原个人文件，也不会把个人浏览器存储上传；云端版代码公开也不会将数据库一并公开。原私有站点的访问范围保持原状。

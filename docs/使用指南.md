# 使用指南

## 独立版开始使用

下载并解压，打开根目录 `每日事件.html`。首次是空白工作区，没有预置的个人课程、示例任务或使用记录。固定使用同一个浏览器和文件位置；不同浏览器、无痕窗口、文件路径或域名可能有不同存储。浏览器禁止本地存储时会出现保存提示，请先导出数据。

## 推荐工作流

1. **先全部列出来**：点“新增事件”，输入名字，日期留空，保存。继续添加其他事情。
2. **集中分配日期**：从待办池拖到某天安排。手机抓右侧六点手柄，移动到日期区，出现放置指示后松手。
3. **按变化调整**：拖到另一天改期，拖回待办池暂缓，在同一天内拖动调整先后。
4. **回顾与完成**：勾选完成。回到今天后，在日期区向下拉回看前几天；滑到顶部继续拉可加载更早一周，也可以选择日期直接跳转。
5. **修改信息**：点“…”→“编辑事件”；删除也在这个菜单里，执行时会要求确认。菜单中没有上移/下移项，顺序由拖动完成。

手机上下滑动卡片正文只用于浏览，不会触发拖动。拖动过程中靠近日期区边缘并短暂停留，可以继续滚动；想调整到很远的日期，可直接编辑事件的“直接安排日期”。

## 备份、转移、导入

独立版在顶部“备份”菜单选择“导出备份”；云端版在“账户”菜单选择。浏览器会下载包含当前事件、顺序和外观设置的 JSON。

手工换设备：原设备导出 JSON → 私下传给新设备 → 新设备打开对应版本 → 导入备份 → 确认替换。**导入会替换当前工作区，不是追加合并**，先分别导出两端再操作。云端导入后需等待“已同步”，其他设备再检查更新。

旧 HTML 没有导出按钮时，应先保留原浏览器和原文件，不要清理缓存；新版的导入只能读取 JSON，直接把旧 HTML 拖入导入框无法取得浏览器记录。升级同一分享版文件时尽量保持路径不变。不同保存命名空间的原私人版与公开分享版不会自行读取对方记录，迁移需从原版本导出或使用经过核对的转换流程。

## 云端版登录与同步

部署完成后，电脑和手机打开**同一个部署地址**并登录**同一个账号**。不要在一个设备打开本地 HTML、另一个打开云端地址后期待同步。修改后检查同步状态，必要时点“立即同步”。出现冲突时先导出本机备份，再选择保留哪一端。无网、缓存不可用或保存失败时按页面提示处理，未确认保存前不要关闭页面。

## 电脑桌面快捷方式

Windows 桌面右键 → 新建 → 快捷方式 → 粘贴你自己浏览器里使用的完整云端工作台网址 → 下一步 → 命名“循日录”。双击后用默认浏览器打开，仍使用该浏览器的登录状态。

独立 HTML 可对文件右键创建快捷方式，保持原文件位置稳定。快捷方式仅是入口，不提供同步，也不包含记录。公开包不附带任何个人私有网站地址。

## 常见情况

- 看不到旧记录：确认是否同浏览器、同地址/文件路径、同账号、同版本；先检查这些，再考虑导入，避免把空数据当作备份覆盖。
- 手机页面还显示旧菜单：刷新页面；必要时关闭再打开该网页。不要为了刷新直接清理保存数据。
- 本机空间不足或禁止存储：先导出 JSON，在保留当前页面的情况下处理浏览器设置，然后重试。
- 公开网页只是代码下载：GitHub 仓库和 Pages 不提供此项目的云端身份/数据库服务。
